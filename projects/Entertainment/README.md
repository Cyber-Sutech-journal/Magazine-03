About The Project


**ticktask** is a desktop project management application built with Python and CustomTkinter.

**Ticktask** is a desktop project management application built with Python and CustomTkinter.


The main idea of the application is simple:

 **"Am I actually ahead of my deadline, or am I just feeling productive?"**


ticktask helps users manage projects by showing both:

tiktask helps users manage projects by showing both:


- How much of the project has been completed
- How much of the available project time has already passed

This makes it easier to understand whether a project is **on track, behind schedule, or in danger**.
